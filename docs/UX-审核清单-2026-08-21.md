# VerbTask UX/HCI 审核清单（2026-08-21）

> 目的：体验导向审核——不是测"功能对不对"，而是测"好不好用、是否困惑、有无摩擦、好不好看"。
> 方法：真实桌面引擎截图取证（浅色 + 深色抽查）+ 视觉模型分析 + 代码交叉核对，按尼尔森启发式 + 桌面/视觉专项逐项填表。
> 版本基准：v0.4.7 界面（内存仓库 seed 代表性数据，不触碰真实用户数据）。
> 状态：⚠️ 待取证 / ✅ 通过 / ❌ 问题(P0-P2) / ⏭ 不适用
