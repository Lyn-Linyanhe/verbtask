# VerbTask Android（手机端）专项审查（2026-08-21）

> 背景：用户目标"完成计划后关注手机端"。本文件记录 Android 工程现状、构建修复、真机（API35 模拟器）验证结果与遗留建议。
> 证据：`build/app/outputs/flutter-apk/app-debug.apk`（152MB debug）；模拟器截图 `build/ux_shots/android_*.png`（gitignored）。

## 1. 结论
Android 端**可以正常构建并在模拟器（API 35）运行**，首页/设置页渲染正常、无崩溃；本轮修复了 2 个阻止/劣化问题：
1. **compileSdk 35 → 36**：`integration_test` 依赖要求 compileSdk≥36，原 35 直接导致 `flutter build apk` 失败；升级后构建成功（Gradle 自动补齐 android-36 平台）。
2. **设置页"Windows 系统"分区对 Android 隐藏**：原在任何平台都显示托盘/自启/置顶三个"死开关"；现用 `if (Platform.isWindows)` 包裹，真机确认为空。

## 2. 构建链
- `flutter build apk --debug` ✅ 产物 `build/app/outputs/flutter-apk/app-debug.apk`
- compileSdk=36 / targetSdk=35 / minSdk=flutter 默认；release 暂用 debug 签名（`build.gradle.kts`）
- 安卓工具链在 `D:\SmartWardrobeTools\android-sdk`（SDK 35，已接受全部许可）；doctor 提示"需 SDK 36 与 BuildTools 28.0.3"，实际构建已自动补齐 36，BuildTools 由 AGP 自动解析
- 警告（非阻塞）：`workmanager` 插件仍直接应用 Kotlin Gradle Plugin，未来 Flutter 版本可能要求迁移到 Built-in Kotlin——**需关注上游升级**

## 3. 真机（模拟器 SmartWardrobeApi35，Android 15/API35）验证
- 安装+冷启动正常；首页（收件箱空态）布局适配手机（1080×2400 @420dpi），无崩溃
- 设置页可见分区：语言 / 外观 / LLM增强解析 / 同步与提醒（+ 配对）；**不含 Windows 专属项**
- 无异常/报错弹窗（红色 DEBUG 角标为 debug 构建产物，正式版无）

## 4. 通知与后台（重点项，均已就绪）
- 清单权限齐全：`POST_NOTIFICATIONS`(13+)、`SCHEDULE_EXACT_ALARM`、`RECEIVE_BOOT_COMPLETED`、`INTERNET`、`ACCESS_NETWORK_STATE`
- 运行时权限：启动时 `requestNotificationsPermission()`（Android 13+ 系统弹窗）
- 提醒调度根据精确闹钟能力动态选择：可用时使用 `AndroidScheduleMode.exactAllowWhileIdle`，不可用时回退到 `AndroidScheduleMode.inexactAllowWhileIdle`；回退模式可能出现分钟级延迟
- 后台周期同步：`Workmanager.init + registerPeriodicTask`（`core/sync/background_sync.dart`），失败有 `catchError` 兜底

## 5. 平台通道安全
- 桌面专属调用均有 `Platform.isWindows` 守卫：`WindowsTray.apply`、`Autostart.setEnabled`、`WindowControl.enterMini/setAlwaysOnTop/startDragging`——Android 上不会报 `MissingPluginException`
- 悬浮速记在 Android 上退化为"整页速记"（窗口控制 no-op），可正常录入

## 6. 遗留建议（未本轮实施）
- **Release 签名**：当前 release 用 debug 签名，仅适合直装 APK；上架或分发需生成正式签名 keystore
- **通知权限时机**：首次启动即请求可能稍显突兀；可改为"开启提醒/设置页首次进入时"再请求
- **App 品牌**：label/图标仍用默认"Verb Task"与占位图标；建议补充品牌图标与图标集（adaptive icon 各家尺寸）
- **精确闹钟**：已接入 `requestExactAlarmsPermission()` 请求和 `canScheduleExactNotifications()` 探测；可用时使用 `exactAllowWhileIdle`，不可用时回退 `inexactAllowWhileIdle`
- **模拟器/工具链**：本机 Android SDK 路径归属旧工程目录（SmartWardrobeTools），建议后续统一 SDK 路径或同步 team 配置
