## 1. 发现明细

### 🔴 P1（明显摩擦，建议本轮优先修）

**P1-1 回收站「彻底删除」无二次确认 —— 不可恢复操作一键到底**
- 证据：`07_bin_light.png`；`lib/ui/pages/recycle_bin_page.dart` `_BoardTask` 旁 `deletePermanent` 直接触发 `service.deletePermanent(t)`（物理移除、不同步、不可恢复），无 AlertDialog。
- 影响：误点即永久丢失，且与「清单删除有确认」「普通删除进回收站」的既有防错习惯不一致。
- 建议：彻底删除前弹确认（含"此操作不可恢复"）；或提供撤销 SnackBar。

**P1-2 任务编辑页「保存」按钮在折叠线以下，默认看不到**
- 证据：`05_edit_light.png`（视口内无保存按钮）；`lib/ui/pages/task_edit_page.dart` 正文为 `ListView`，`FilledButton`（保存）为列表末项，900×620 默认视口需滚动才见。
- 影响：用户改完不知道在哪保存/以为没保存按钮，摩擦明显。
- 建议：保存按钮固定到底部（sticky footer）或放 AppBar 操作位；同时给"取消/返回"第二级样式。

**P1-3 任务优先级（高/紧急）在首页与看板卡片上完全不可见**
- 证据：`01_home_inbox_light.png`、`03_board_light.png`；`home_page._TaskCard`、`board_page._BoardTask` 均**未渲染 priority**。
- 影响：在确认框/编辑页设了「高/紧急」，回到列表看不到，只能靠按截止排序去猜，违背"输入的信息要能被看见"。
- 建议：卡片加优先级标识（红/橙"!"或色点）+ 支持"按优先级排序"。

**P1-4 列表里「进行中」与「未开始」几乎无法区分**
- 证据：`01_home_inbox_light.png`；`_TaskCard` 状态仅靠一个 4px 圆点颜色（primary vs outline），复选框只表达"完成/未完成"。
- 影响：用户无法一眼看出哪些任务正在做。
- 建议：给"进行中"更强标识（左侧竖条 / 状态徽章 / 卡片底色），并让复选框支持三态或明确状态切换。

**P1-5 首页「快速录入」与「搜索」两个输入框样式几乎一样，易误用**
- 证据：`01_home_inbox_light.png`、`02_home_search_light.png`（视觉模型两次指出"两个框一样，分不清功能"）；`home_page` 中两个 TextField 用同一 `InputDecoration`，仅 hint 文本不同。
- 影响：用户可能把任务敲进搜索框，或把关键词敲进录入框。
- 建议：录入框保留 "+" 图标与"添加任务…"并加一个主按钮式入口；搜索框差异化（更窄、带放大镜、独立区域）。

**P1-6 看板移动任务靠卡片右上角 ⋮ 菜单，无拖拽、无提示、难发现**
- 证据：`03_board_light.png`、`12_more_menu.png`；`board_page.dart` 每个卡片仅 `PopupMenuButton` 提供状态切换，无拖放。
- 影响：看板的直觉玩法（拖卡）缺失；首次用户想不到点 ⋮。
- 建议：实现拖放（桌面 main）或卡片上显性"←/→ 移到某列"按钮；列空时给出"添加到此列"入口。

### 🟠 P2（优化项）

- **P2-1 「有期限」标签冗余**：卡片左侧已显示具体日期时间，右侧再贴"有期限"纯属重复（`_DueChip`）。仅保留"已逾期/今天"这类有信息量的状态即可。
- **P2-2 视图 Tab 选中态对比不足**：`收件箱/清单/…` 选中仅靠字重+浅紫底（截图 01），识别弱。建议加深/加描边。
- **P2-3 次要文字对比度偏低**：截止时间、"有期限"、占位符、设置副文案（浅色≈#667085、深色≈#6B7280）在多数屏幕上偏浅，弱光下难读。建议提到 WCAG AA。
- **P2-4 LLM 配置区对非技术用户仍是门槛**：Base URL / API Key / 模型 / 获取模型图标（截图中只有一个"↓"图标、无语义）对普通用户难懂；且 base/key 未填时点"获取模型"只弹通用"获取模型失败"（`settings_page._fetchModels`），不提示先填字段。建议：按钮改文字"获取模型"、加 tooltip/帮助链接、空配置时给出明确引导。
- **P2-5 空态缺点引导**：空收件箱只有图标+"收件箱是空的/把要做的事记下来"（`EmptyState`），没有"怎么开始"的示例。建议补一句"试试输入『明天3点交周报』"。
- **P2-6 编辑页「仅日期」开关与日期按钮从属关系不直观**：日期选择下方才是"仅日期"开关，视觉未成组（`task_edit_page` scheduling 区）。建议同组/加说明。
- **P2-7 看板空列与滚动缺提示**：空列只有"无"；列长时无滚动暗示。建议空列引导文案 + 列尾计数/滚动条感知。
- **P2-8 回收站/清单管理图标细节**：`07_bin_light.png` 恢复/删除图标对比弱、尺寸偏小、无 hover 反馈。建议统一并增强反馈。
- **P2-9 设置深色下控件热区**：`10_settings_dark.png` "模型"字段右侧按钮图标小、热区不足、语言下拉箭头孤立。建议放大热区 + tooltip。
- **P2-10 桌面微交互欠缺**：多界面无 hover 高亮/轻动画，桌面端略"死板"。建议补 hover、选中、递进动画。
- **P2-11** 「更多」弹出菜单在右上角会覆盖相邻按钮区域（`12_more_menu`），可接受但注意点击边界；建议给菜单项保留充足外间距/点外即关已有。

### ✅ 做得好（建议保持）

- 首页三段式信息架构清晰（标题 → 录入/搜索 → 视图 → 筛选 → 列表），层级分明。
- NLP 确认弹窗字段完整（标题/截止/重复/清单/提醒/优先级/来源），遮罩合适、主次按钮分明。
- 状态色系统统一：逾期=红、今天/进行中=蓝（青）、完成=绿，浅/深主题都可辨。
- 设置页卡片分区清晰、深色质感好；LLM「数据出本机」有知情同意弹窗 + 设置页说明文案。
- 速记小窗有拖动把手与恢复按钮，窗口尺寸小巧（主窗 900×600 / 速记 420×260）。
- 防错有基础：普通删除走回收站（软删）、清单删除有确认、空标题有守卫。
- 图标按钮普遍带 tooltip；中英双语完整。
