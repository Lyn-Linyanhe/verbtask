## 三、发现并已修复的缺陷

### P1-1 中文解析误删"周"（高影响）
- **现象**：录入「明天下午3点 交周报 高」→ 标题解析成「交 报」；「周报」「周末」的"周"被吞。
- **根因**：`lib/core/nlp/zh_parser.dart` 清洗正则 `(?:下|本|这|那)?(?:周|星期|礼拜)[一二三四五六日天]?` 前后缀均可选，裸"周"也被剥离。
- **修复**：改为「带前缀可选带数字」或「无前缀必须带星期数字」；补了 `明天下午3点 交周报 高 / 周报 / 周末 / 每周三开周会 / 下周三下午3点 交报告` 用例。
- **提交**：`83dee98`
- **验证**：修复后标题正确保留「交周报」；全量测试通过。

### P1-2 托盘常驻开关失效
- **现象**：设置关掉「托盘常驻」，托盘仍然存在、关闭仍隐藏后台。
- **根因**：`main.dart` 无条件 `WindowsTray.init()`，未读 `settings.trayEnabled`；tray 有 `destroy()` 能力但从未用。
- **修复**：`WindowsTray.init(enabled:)` + `apply(enabled)` 创建/销毁托盘 + 按开关决定 `setPreventClose`。
- **提交**：`3aebf24`

### P1-3 开机自启开关失效（纯假开关）
- **现象**：勾选/取消「开机自启」只写 JSON，系统无任何变化。
- **根因**：`autostartEnabled` 仅存设置，无注册表/启动项实现。
- **修复**：新增 `lib/app/autostart.dart`，通过 HKCU Run 注册表写入/删除当前 exe，含查询幂等。
- **验证**：真实注册表实测开启→存在 / 关闭→删除，不留残留。
- **提交**：`3aebf24`

### P2-4 系统代理未跟随（历史，已在此前版本修复）
- **现象**：用 OpenAI 等需代理的服务直连超时（Dart HttpClient 不读 Windows 系统代理）。
- **修复**：`lib/core/net/system_proxy.dart` 解析注册表/环境变量代理，`LlmClient` 默认使用带代理的客户端。
- **提交**：`ccadc7d` → v0.4.3
- **验证**：修复后连 OpenAI `超时` → `HTTP 401（已连通）`，连 DeepSeek 401（连通、仅缺 key）。

### P2-5 LLM 模型不可配置（历史，v0.4.1）
- 修复：加「模型」输入框 + 设置页 📥 拉取 `/models` 可用模型列表（v0.4.2）。
- 提交：`3a55f39` / `49f265a`
