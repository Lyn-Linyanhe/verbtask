# VerbTask 竞品调研报告：国内产品补充

> 日期：2026-08-23  
> 范围：国内个人任务/便签产品，以及国内协作产品中可借鉴的任务、日程、提醒交互。  
> 目标：为 VerbTask 的 Android + Windows、无账号、本地优先、局域网同步定位提供功能和 UI 参考。  
> 说明：本报告只把官方页面明确写出的能力作为“已确认”；第三方搜索摘要、不可访问页面和推测均单独标注。

## 1. 结论先行

### 最值得直接参考的三个方向

1. **敬业签：中文场景和桌面常驻的直接参考。** 它把“便签、待办、提醒、日历、时间轴”放在同一产品中，Windows 端强调桌面便签和快速查看；公历/农历、重复提醒、延时提醒和误删恢复都很贴近国内用户习惯。代价是云端账号和厂商云同步，与 VerbTask 的无账号本地优先不同。
2. **滴答清单：任务管理结构和快速录入的直接参考。** 官方页面明确展示快速添加、智能识别时间、清单、过滤器、标签、列表/看板/时间线、多种重复提醒。它的功能覆盖很完整，但账号、云同步和大量效率模块会把产品做重，VerbTask 只应抽取核心交互。
3. **钉钉/飞书：通知状态和日程交互的参考，不是产品定位参考。** 钉钉的 DING 强提醒、AI 生成行动清单，飞书日历的邀请/开始/变更/冲突提醒值得借鉴；组织、权限、审批、会议室和企业协作不应进入 VerbTask 的核心范围。

### 对 VerbTask 的明确建议

- **定位边界：** 本报告中的“任务/待办”仅指需要记录、查看或提醒的事项，是通用称呼，不代表 VerbTask 要做番茄 ToDo 式的专注产品。VerbTask 只做提醒与记事；番茄 ToDo 的专注计时、自律和学习场景只作为独立竞品观察，不纳入功能范围。
- 默认首页仍使用“收件箱 + 今日/即将到期”两条高频入口；不要照搬企业产品的多级工作台。
- 快速录入入口必须常驻且一键可达：Android 采用明显的新增按钮/底部入口，Windows 采用紧凑输入条、全局快捷键和悬浮速记。
- 输入“明天下午3点交周报，高，之后每周一提醒我”后，先展示可编辑确认面板；提醒、重复、截止时间和“不要提醒”必须是独立字段，不能只靠标题文本展示。
- 借鉴敬业签的时间轴/回收能力，但数据仍保存在本地；同步只传输用户主动配对的局域网数据。
- 借鉴 TickTick 的列表/看板/时间线选择，但 v1 只保留列表和看板，日历/时间线作为后续视图，不让首屏变成控制面板。
- 借鉴飞书/钉钉的“为什么提醒、什么时候提醒、提醒是否成功”反馈，但不引入短信、电话、第三方账号等复杂渠道。

#### UI 观察

官网 Windows 页面不是客户端本身，但视觉模型核对出几个可迁移模式：

- 一个高对比主按钮承担“免费下载”，备用下载降级为次要链接；主任务页也应只有一个主新增动作。
- 平台图标横排作为二级导航，易于扫描；VerbTask 可把它转化为“列表/看板/日历”视图切换，但手机端不能照搬长横排。
- 版本号、版权和认证信息放在主操作附近但不抢焦点；VerbTask 可将“最近同步、数据位置、解析模式”做成安静的状态信息。
- 官网首屏导航项目较多，适合桌面下载页，不适合 VerbTask 的手机任务首屏。

#### 对 VerbTask 的启示与边界

- **吸收：** 小巧桌面常驻、快速查看、复杂提醒、时间轴和误删恢复、中文公历/农历语义。
- **不照搬：** 云账号、短信/电话等增值提醒、多端账号体系、企业团签。
- **验证限制：** 已下载官方安装包 `D:\VerbTask-Research\downloads\Jingyeqian-win-v3.4.2.0.exe`，大小 `99,538,496` 字节，SHA-256 为 `3CDC11D1998A232F5F0D0BEC45B4320F679DBBFCA7D8B14E125B2EFD892004C4`。本轮没有完成安装后的客户端体验，因此客户端内部 UI 不作结论。

**定位：跨平台个人效率工具，国内团队产品，面向全球市场。** 本报告按中文使用场景纳入国内产品补充；其官方页面同时提供中文界面和 Windows/Android 客户端。

| 项目 | 核验结果 |
|---|---|
| 官方来源 | [功能介绍](https://ticktick.com/features)、[下载应用](https://ticktick.com/download)、[关于我们](https://ticktick.com/about)、[官方帮助中心](https://help.ticktick.com/) |
| 平台 | A：iOS/iPadOS、Android、Windows、macOS、Linux、Web、浏览器插件等入口 |
| 快速录入 | A：第三方应用、手机小组件、桌面全局快捷键；官方功能页强调快速添加任务 |
| 时间识别 | A：官方明确写“智能识别时间”，输入文本时识别时间并设置提醒 |
| 组织方式 | A：清单、过滤器、标签；支持共享清单和任务指派，但后者不是 VerbTask 需求 |
| 提醒 | A：多个提醒、结束时提醒、持续提醒、邮件提醒、每日提醒；位置提醒在官方页标注为 iOS 能力 |
| 重复 | A：每周、每月、每年、自定义等；帮助中心列出跳过当前周期等问题 |
| 视图 | A：列表、看板、年/月/周/日程/多日、时间线 |
| 其他模块 | A：番茄专注、习惯、四象限、倒数纪念日、统计、主题等 |
| 账号/同步 | B：官网以登录/注册和跨平台产品为核心入口；本轮未登录，不把具体账号策略和同步协议当作客户端实测结论 |

#### UI 观察

- 官方关于页明确表达“常用动作靠近手边，高级选项只在需要时出现”，这是 VerbTask 应保留的交互原则。
- 功能页的多视图表达清楚：列表解决执行，看板解决状态，时间线解决排期；VerbTask 可以沿用同一心智模型。
- 官方营销页首屏留白很大、信息密度低，这是品牌页优点，不适合直接复制到任务清单；工作流页面应提高密度、左对齐并优先显示任务内容。
- 帮助中心把“重复任务跳过当前周期”“未提醒怎么办”“批量编辑/删除”等按问题组织，说明这些是高频摩擦点；VerbTask 的帮助和错误提示也应使用问题导向文案。

#### 对 VerbTask 的启示与边界

- **吸收：** 快速添加、时间识别、标签/过滤、列表与看板切换、重复任务确认、桌面快捷键。
- **不照搬：** 习惯、番茄钟、倒数、统计、协作等大量模块，避免让个人小工具变成综合效率平台。
- **必须改进：** VerbTask 的解析结果要在提交前确认；本地中文解析优先，LLM 仅作为可选补充，并显示数据外发提示。

### 3.3 番茄 ToDo

**定位线索：专注计时 + 待办 + 自律。**

- 搜索结果中出现 `music1.tomatodo.cn`（“番茄ToDo官方网站”）和 `pc.fanqietodo.cn`（桌面计时插件）入口。

## 4. 国内协作/日程产品：只提取交互经验

### 4.1 钉钉

官方来源：[钉钉官网](https://www.dingtalk.com/)。

官网核验到：

- 覆盖桌面、网页和移动端，并提供下载入口。
- 产品导航中有“钉钉日历”“钉钉项目”“DING 消息”等模块。
- DING 支持短信、语音、电话等强触达，并展示查看/接收状态；这是“提醒是否送达/是否处理”的强反馈范例。
- AI 助理能从会议、销售、面试、沟通等场景列出行动清单，并可同步到 AI 表格。
- 钉钉日历强调日程信息触达、协同联动和订阅日历。

对 VerbTask 的可借鉴点：

- 提醒卡片要显示来源、时间、处理状态和下一步，不要只弹一条无上下文的“到点提醒”。
- 快速录入后的行动清单可以先预览再确认；这与 VerbTask 的 NLP 确认弹窗方向一致。
- 不引入通讯录、审批、群聊、企业权限和电话短信渠道；个人任务场景只保留本地通知。

### 4.2 飞书

官方来源：[飞书官网](https://www.feishu.cn/)、[飞书日历](https://www.feishu.cn/product/calendar)。

飞书日历官方页面核验到：

- 可订阅同事日历并查看忙闲状态。
- 可通过日历发出会议邀约，参与者收到通知，日程同步到日历。
- 支持公共日历，用于项目排期、节假日安排等共享信息。
- 日历助手会在收到邀请、日程开始前、时间地点变更或日程冲突时提醒。
- 日历与即时沟通、在线文档深度整合。

对 VerbTask 的可借鉴点：

- 将“到期前提醒”和“任务发生变化”区分成不同反馈类型，文案要说明变化原因。
- 冲突、失败和变更应有可见状态，不要静默覆盖用户输入。
- 个人版本可做“本地日历视图”和“重复任务冲突提示”，不做成员忙闲、会议室和协作文档。

## 7. VerbTask 的 UI 取舍

### 建议保留

1. **收件箱默认入口。** 新任务不要求先选分类；详情里再补清单、标签、截止日期和提醒。
2. **一个主新增动作。** Android 用 48dp 以上触控热区和清晰的新增按钮；Windows 用快捷键、输入条和悬浮速记三种等价入口。
3. **状态与视图分离。** 未开始/进行中/完成是任务状态；列表/看板/日历是查看方式。不要把“看板列”误当成项目分类。
4. **确认式 NLP。** 输入内容、解析结果、未识别片段和最终将写入的字段一次展示；用户可以逐项修改、取消或回到手动编辑。
5. **提醒状态透明。** 每条任务显示“无提醒/提前 X 分钟/精确时刻”；全局默认只在任务未做选择时继承，明确关闭要有独立状态。
6. **删除可恢复。** 回收站、时间轴和恢复入口应比设置页更容易找到；永久删除才需要二次确认。

### 建议避免

- 首屏同时放项目、清单、标签、过滤器、日历、习惯、番茄钟、统计等十余个模块。
- 把企业产品的组织/成员/审批/会议室模型带进个人 App。
- 用浅灰小字承载截止日期、提醒失败或同步失败等关键状态。
- 复制营销页的大留白和居中英雄布局到任务列表；工作流页面应左对齐、可扫描、信息密度适中。
- 在手机上使用长横向工具栏；优先底部导航、抽屉或底部面板。
